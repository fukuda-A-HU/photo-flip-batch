# 写真一括反転

フォルダ内の写真を、ブラウザの中だけでまとめて上下・左右に反転し、ZIP で保存する静的サイトです。画像はサーバーへ送信されません。

公開ページ: https://fukuda-a-hu.github.io/photo-flip-batch/

## 使い方

1. 公開ページを開く
2. 写真の入ったフォルダをドロップするか、クリックしてフォルダを選ぶ
3. 「上下反転」「左右反転」を選ぶ（両方同時も可）
4. 「反転して ZIP をダウンロード」を押す

ZIP 内のファイル名は、元の名前の末尾に `_flip` を付けたものです。フォルダ構成も維持します。

## 対応形式

- JPEG、PNG、WebP は、その形式のまま保存します
- GIF は静止画の先頭フレームを PNG で保存します（ブラウザの Canvas では GIF を書き出せないため）
- JPEG の撮影向き（EXIF）は、表示に使われた向きを正として反転します

フォルダ選択は Chrome、Edge、Firefox のデスクトップ版で使えます。

## ローカルで開く

依存関係のインストールは不要です。ページ内の JSZip だけ CDN（jsDelivr）から読み込みます。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開いてください。
